# 角色与目标

你是一个资深的前端与编辑器开发专家。请根据以上json，编写一个基于 [请填写技术栈，例如：Electron + Vue3 + Element Plus / Web网页版] 的轻量级、类 Cocos Creator 3D 的节点树 UI 编辑工具。所有路径操作均基于当前打开的项目根目录。

# 核心数据结构

1. UI界面：一个 JSON 文件对应一个 UI 界面。
2. 组件定义（./components.json）：存储系统支持的所有组件类型及其默认属性字段。

# 界面布局与功能要求

## 1. 顶部导航栏 (Top Bar)

- 包含按钮：新建项目、导入项目、新建UI界面、导入UI界面、导出UI界面。
- 包含“编辑组件库”按钮：点击弹出 Modal 框，内含 CodeEditor 展示 `./components.json` 的文本内容。点击“保存”时，直接写入本地文件并更新编辑器内存中的组件预设。

## 2. 左侧控制面板 (Left Panel)

- **左上方（节点树区）**：
    - 树状层级展示当前 UI JSON 的节点结构。
    - 支持节点间的拖拽（Drag & Drop）以改变层级父子关系或同级排序。
    - 支持右键菜单：新建子节点、复制节点、删除节点。
- **左下方（项目文件列表）**：
    - 展示当前项目目录下的文件。支持双击 `.json` 切换当前编辑的 UI 界面。

## 3. 中间区域 (Stage / Canvas)

- 渲染当前节点树的 UI 视图。
- 左键点击某个 UI 元素，左侧节点树同步高亮选中，右侧属性栏切换为该节点。
- [可选拓展] 支持在画布上直接拖拽元素改变其基础坐标(x, y)。

## 4. 右侧属性编辑面板 (Inspector)

- **节点基础属性**：顶部固定显示当前选中的节点名称（Name）、激活状态（Active）等。下方有“新建子节点”，“复制节点”，“粘贴节点”，“删除节点”按钮。
- **组件管理**：
    - 提供一个“添加组件”按钮，点击后下拉列出 `./components.json` 中定义的所有可用组件。
    - 动态渲染当前节点已挂载的组件列表。每个组件为一个卡片：
        - 标题栏：左侧显示组件类型名称，右侧包含“删除组件”按钮和“折叠/展开”箭头。
        - 内容区（展开时）：根据组件属性类型渲染对应的输入框（数字、文本、布尔开关）。
- **特殊组件逻辑**：若节点挂载了 `SpriteComponent` 组件，其 `framePath` 属性输入框支持作为拖拽目标（Drop Target）。

## 5. 底部资源管理器 (Asset Pipeline)

- 过滤并只显示当前项目中的图片类型文件（.png, .jpg）。
- 资源库中的图片支持拖拽（Drag）。允许将其拖拽到右侧 `SpriteComponent` 的 `framePath` 属性框内，释放后自动将该属性值修改为该图片的相对路径。

# 数据流与同步机制（核心）

- 采用单向数据流结合状态管理。编辑器内存中维护一个响应式的 `currentUIData` 对象。
- UI 画布、左侧树、右侧属性栏的所有修改**必须立即更新** `currentUIData` 并触发视图重绘。
- 内存数据写入本地 JSON 文件需采取**防抖机制（Debounce, 如300ms）**或在**输入框失去焦点（Blur）时触发**，以避免高频 I/O 导致输入卡顿或光标丢失。
- 外部手动修改 JSON 文件时，编辑器需监听文件变化并平滑重载数据。
